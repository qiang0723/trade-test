### 数据源对比

| 数据类型 | Binance (当前) | Coinglass | 差异说明 |

| 资金费率 | ✅ 单交易所 | ✅ OI加权聚合 | Coinglass更准确 |
| 持仓量(OI) | ✅ 仅Binance | ✅ 跨交易所聚合 | Coinglass覆盖更广 |

| **清算热力图** | ❌ 无 | ✅ 独有 | **核心差异** |
| **实时爆仓** | ❌ 无 | ✅ 独有 | **核心差异** |
| 订单簿深度 | ✅ 基础 | ✅ L2/L3详细 | Coinglass更细 |

### Coinglass独有数据价值分析

#### 1. 清算热力图 (Liquidation Heatmap) ⭐⭐⭐⭐⭐
```
价值：
- 识别价格关键支撑/阻力位
- 预判清算级联风险
- 发现真正的"痛点价位"

应用场景：
- 当前价格接近大量清算聚集区 → 降低置信度（波动风险）
- 价格突破清算区 → 可能引发级联，增加趋势信号
- 用于优化入场/出场点位

API端点：
- /api/futures/liquidation/heatmap
- 返回：price_level, liquidation_value, leverage_distribution
```

#### 2. 跨交易所聚合OI ⭐⭐⭐⭐
```
价值：
- 当前仅用Binance OI，可能只反映30-40%市场
- 聚合OI更准确判断资金拥挤度
- 可识别"Binance独有"vs"全市场共识"的差异

API端点：
- /api/futures/openInterest/aggregated-history
- 返回：timestamp, oi_value, exchange_breakdown
```

#### 3. 实时爆仓数据 ⭐⭐⭐⭐
```
价值：
- 短时间大量爆仓 → 市场可能反转
- 可作为"极端事件"信号触发器
- 辅助判断趋势终结点

API端点：
- /api/futures/liquidation/latest
- 返回：timestamp, side, size, price
```

#### 4. OI加权资金费率 ⭐⭐⭐
```
价值：
- 比单交易所费率更准确反映市场情绪
- 避免被单一交易所异常值干扰

API端点：
- /api/futures/fundingRate/oi-weight
```

## 五、Coinglass决策融合详解

### 融合架构
```
数据流：
Binance数据 → FeatureSnapshot → DecisionCore
                    ↓
              SignalEnhancer ← Coinglass数据
                    ↓
              最终决策 + Coinglass标签/加分
```

### 融合维度

| 维度 | 数据源 | 信号 | 加分/惩罚 |
|------|--------|------|-----------|
| 清算分析 | liquidation_summary | 多头清算>70%+做多 | +8~+12 (潜在反弹) |
| | | 空头清算>70%+做空 | +8~+12 (潜在回调) |
| | | 顺势清算 | -3 (风险警告) |
| 情绪分析 | fear_greed | 极度恐惧(<25)+做多 | +6 (逆向机会) |
| | | 极度贪婪(>75)+做空 | +6 (逆向机会) |
| 拥挤检测 | long_short_ratio | 多头>70%+做多 | -5 (拥挤惩罚) |
| | | 空头>70%+做空 | -5 (拥挤惩罚) |
| | | 逆向信号 | +8 (逆向加分) |
| OI分析 | oi_history | OI激增>3%+趋势 | +5 (趋势确认) |
| | | OI下降<-2% | -3 (趋势耗竭) |
| 费率分析 | funding_history | 极端费率+顺势 | -5 (拥挤风险) |

### 新增ReasonTag
- `liquidation_imbalance_long` - 多头清算聚集
- `liquidation_imbalance_short` - 空头清算聚集
- `liquidation_cascade_risk` - 清算级联风险
- `aggregated_oi_surge` - 全市场OI激增
- `aggregated_oi_drop` - 全市场OI下降

### 配置参数 (l1_thresholds.yaml)
```yaml
coinglass:
  enabled: true
  cache_ttl_seconds: 60
  fusion:
    liquidation_proximity_pct: 0.02
    oi_surge_threshold: 0.05
    oi_drop_threshold: -0.03
    imbalance_threshold: 0.30
```
